## 🚀 Ключевые возможности

### ⏰ 1. Высокоточный авто-сабмит квоты (00:00:00 GMT+8 / Пекин)
- **Атомное время NTP**: Синхронизация часов по серверам `time.google.com` с точностью до 1 миллисекунды.
- **Динамический замер RTT**: Замеряет пинг до серверов Xiaomi и рассчитывает отправку пакетов `apply/bl-auth` так, чтобы они прикоснулись к серверу ровно в **+15 мс** после полуночи.
- **Фоновое пробуждение (AlarmManager)**: Процесс размораживается из любого фонового сна MIUI/HyperOS за 15 секунд до 00:00:00.

### 🏆 2. Реальный Авто-Фарм XP и Квестов
- **Выполнение квестов через API**: Работает напрямую с официальным эндпоинтом `task/finish` через Retrofit и сессионные токены.
- **Прокачка уровня (+150 XP в день)**: Автоматический ежедневный чек-ин, чтение постов, подписки и активности.
- **Умный приоритет квоты**: С 23:55 до 00:05 (Пекин) авто-квесты автоматически уходят в паузу, отдавая 100% сети и CPU под заявку на разблокировку.

### 📊 3. Мониторинг уровня и XP в реальном времени
- Отображение текущего уровня (Lvl), набранного XP, максимума XP и остатка до следующего уровня прямо на вкладке **«🏆 XP Задания»**.

## 🛠 Инструкция по установке и запуску

1. Скачайте файл **`XiaomiCommunity_MenaceMod.apk`** со страницы релиза.
2. Установите приложение на смартфон и войдите в свой Mi Аккаунт.
3. Нажмите на плавающую кнопку **`⚡ MENACE v5`**.
4. Включите тумблеры **«АВТО-ПОДАЧА В 00:00:00»** и **«БЕСКОНЕЧНЫЙ ФАРМ XP»**.
